Galio test build (ad-hoc signed, not notarized). Apple Silicon, macOS 15+.

Install
1. Download `Galio.zip` below and unzip it.
2. Move `Galio.app` to Applications.
3. First launch: right-click (or Control-click) Galio → Open → Open. Alternatively System Settings → Privacy & Security → "Open Anyway". This is needed once because the build is not notarized yet.
4. Run League of Legends in Borderless or Windowed mode for the overlay; toggle it with ⌥⇧G.
5. Optional: allow Screen Recording when you first press "Scan cards" (augment tiers in ARAM: Mayhem / Arena). Everything is read on your Mac; nothing is uploaded.

Galio never presses keys or clicks in the game, never reads game memory, never shows other players' stats, and shows augment tiers only (no win rates). Rune / item-set import happens only when you click, outside the live game.
