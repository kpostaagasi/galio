## What exists

- **ClientBridge**: lockfile (custom path setting) with `ps` command-line fallback (`--app-port`, `--remoting-auth-token`; arguments only, never memory); `RiotTLSDelegate` validates against the bundled `riotgames.pem` and otherwise accepts self-signed certs **only for 127.0.0.1**; REST client; WAMP WebSocket (`[5,"OnJsonApiEvent"]`) for gameflow / champ-select / session events with 2 s polling fallback; champ-select model that does not even decode player identities.
- **Modes**: Summoner's Rift (draft/ranked/blind/quickplay/Clash), ARAM, ARAM: Mayhem (KIWI / queue 2400), Arena (CHERRY), URF/ARURF, One for All, Nexus Blitz, Swarm, Brawl, Practice Tool, tutorial, custom (`ModeInfo.classify`).
- **LiveGame**: Live Client Data poller, only while the phase is InProgress/Reconnect.
- **Overlay**: non-activating floating `NSPanel`, draggable, opacity + click-through settings, auto show/hide with the game flow, global hotkey ⌥⇧G (Carbon `RegisterEventHotKey`, listen-only).
- **Static data**: Data Dragon latest version for images, per-champion DDragon JSON cached per patch in Application Support, cached icons (`ImageCache`, disk + memory).
- **Recommendation data**: `data/<patch>/all.json` (+ per-champion files) built by `tools/build_data.py` from Data Dragon, CommunityDragon (champion roles/playstyle, Riot's in-client rune & spell recommendations, augment lists and tooltips) and curated tables (`tools/curated/`). The app loads cache → bundled copy and refreshes from `raw.githubusercontent.com/kpostaagasi/galio/main/data/`.
- **Advisors**: `ChampionAdvisor` (team needs + visible-enemy hints + own mastery, 3–5 options with reasons), `RuneAdvisor` (2–3 pages, shard tweaks vs CC/poke), `SummonerSpellAdvisor`, `SkillOrderAdvisor` (18-level plan + next-skill reminder), `ItemAdvisor` (enemy threat profile from champions + scoreboard items, gold awareness, buildable component), `AugmentAdvisor` (champion-relative S–D tiers, no win rates) + `FuzzyMatcher`.
- **Client actions (click only, refused in game)**: rune page import (replaces Galio's own page; asks before overwriting a user page when the limit is full), summoner spells PATCH (keeps Flash on the player's key), item-set export.
- **Augment OCR**: ScreenCaptureKit capture of the League window (fallback: main display without Galio's windows) + Vision `VNRecognizeTextRequest` (tr-TR, en-US) + fuzzy match; Screen Recording permission requested on first scan; manual search fallback.
- **Mock mode**: `--mock-game <champselect|champselect-locked|ingame|aram|mayhem|arena|postgame>` starts an in-process HTTP server on the loopback interface that impersonates LCU + Live Client; CI launches each scenario and uploads screenshots.

## Tests

XCTest with recorded-style fixtures in `GalioTests/Fixtures` (generated by `tools/make_fixtures.py` in the shapes of the real LCU / Live Client responses) and the mock server.

## Known limitations

- Recommendation data is rule-based + curated (and Riot's in-client rune recommendations) until a Riot API key enables `tools/aggregate_matches.py`; skill max orders are hand-curated per champion.
- Augment tiers are heuristic fits from tooltip keywords and tags (by design: no win rates).
- The overlay only shows above the game in Borderless/Windowed mode (macOS fullscreen spaces hide other windows).
- Builds are ad-hoc signed (no notarization): first launch needs right-click → Open.
- `GameSession` main-actor integration is verified by the mock-game smoke run (screenshots), not by XCTest (main-actor async tests hang in the test host).
